# LaVision Laminates — Website

> **"More than most, and it shows."**  
> A playful, non-boxy, animation-first website for LaVision Laminates — Gujarat’s premier super-stockist and wholesale distributor of decorative surfaces, engineered MDF, calibrated marine plywood, acoustic louvers, and bespoke interior materials.

---

## 🌟 Creative System & Stack

- **Framework:** React (JSX) + Vite
- **Styling:** Tailwind CSS ("Sunlit Studio" color tokens & architectural arch utilities)
- **Motion & Physics:** Framer Motion + GSAP (ScrollTrigger) + Lenis smooth scroll
- **3D Interactive:** Three.js + React Three Fiber + Drei (Virtual 3D Room Experience)
- **Typography:** Self-hosted Clash Display (Headings), General Sans (Body), Shantell Sans (Handwritten Doodles), and Geist Mono (Data/Stats)
- **Brand Positioning:** Strictly Wholesale & Super-Stockist (500+ dealer network across Gujarat)

## 📁 Pages & Routes

- **Home (`/`)**: Light wave hero, stats band, product arches, brand marquees, signature puzzle-piece testimonials, partner tags, and dealer CTA.
- **About (`/about`)**: 14 years legacy, 500+ dealers, vision, 6 "More Than Most" promise pillars, and showroom imagery.
- **Products (`/products` & `/products/:category`)**: 8 specialty product categories with technical specifications, finish swatch trays, and dealer locators.
- **Brands (`/brands` & `/brands/:brand`)**: 8 specialty brand lines (LaVision, Vienna, IFILL, Urban, ColorTrip, Tovin, One Touch, Ultimo).
- **Gallery (`/gallery`)**: 21 high-resolution showroom photos with category filters and modal lightbox.
- **Virtual 3D Room (`/virtual-3d`)**: Interactive 3D stylized interior room viewer with 360° OrbitControls and real-time surface texture switching.
- **Projects (`/projects` & `/projects/:id`)**: Luxury residential, corporate commercial, and hospitality installations across Gujarat.
- **Dealers (`/dealers/find` & `/dealers/become`)**: Searchable Gujarat city directory + dealership application form with confetti celebration.
- **Showrooms (`/showrooms`)**: Rajkot (Tagore Rd) & Ahmedabad (Gota, SG Highway) experience center details, timings, and directions.
- **Contact (`/contact`)**: Wholesale inquiry form and trade desk contacts.
- **Catalogues (`/catalogues`)**: 2026 digital PDF specification catalogue downloads.
- **Legal (`/privacy` & `/terms`)**: Supply terms and privacy disclosures.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
